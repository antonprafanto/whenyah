## Deploy ke GitHub Pages

1. Push ke repo: `git push origin main`
2. Di GitHub, buka **Settings > Pages**
3. Source: **Deploy from a branch**, Branch: `main`, Folder: `/(root)`
4. Simpan dan tunggu ~1 menit

## Tech Stack
